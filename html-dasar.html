HTML Dasar, Heading, Formatting & List

HTML (HyperText Markup Language) adalah bahasa standar pembuatan struktur web. Halaman ini mendemonstrasikan penggunaan tag elemen teks, judul, link, daftar, dan struktur semantik HTML.

Daftar Isi Materi
  • Heading (<h1>-<h6>)
  • Paragraph (<p>)
  • Text Formatting
  • Link & Navigasi (<a>)
  • List (<ul>, <ol>, <dl>)
  • Tag Semantik Layout

Tag Heading (<h1> hingga <h6>)

Heading dalam HTML menentukan hirarki atau tingkat kepetingan sebuah judul pada halaman. Tag <h1> mewakili judul tingkat tertinggi, sedangkan <h6> adalah tingkat terkecil.

HTML Heading Code 
<h1>Heading Utama Level 1 (h1)</h1>
<h2>Sub Judul Level 2 (h2)</h2>
<h3>Sub-Sub Judul Level 3 (h3)</h3>
<h4>Heading Level 4 (h4)</h4>
<h5>Heading Level 5 (h5)</h5>
<h6>Heading Level 6 (h6)</h6>

Paragraph (<p>) & Kutipan

Tag <p> digunakan untuk mengelompokkan teks menjadi sebuah paragraf. HTML secara otomatis memberikan baris baru di atas dan di bawah paragraf.

HTML Paragraph Code 
<p>Ini adalah paragraf pertama yang menjelaskan materi HTML.</p>
<p>Ini adalah paragraf kedua dengan baris baru <br> menggunakan tag &lt;br&gt;.</p>

Text Formatting Tags

HTML menyediakan tag khusus untuk memformat gaya visual dan memberikan makna semantik pada potongan kata/kalimat:

Formatting Code 
<p>
  Teks <strong>Tebal Penting (strong)</strong> dan <b>Biasa Tebal (b)</b>.<br>
  Teks <em>Miring Miring (em)</em> dan <i>Italic biasa (i)</i>.<br>
  Teks dengan <mark>Sorotan Warna (mark)</mark>.<br>
  Formula Kimia: H<sub>2</sub>O (subscript) dan Matematika: X<sup>2</sup> (superscript).<br>
  Harga: <del>Rp 100.000</del> <ins>Rp 75.000</ins>.<br>
  Kode Program: <code>const x = 10;</code> dan tombol <kbd>Ctrl</kbd> + <kbd>C</kbd>.
</p>

Link & Tautan (<a>)

Tag <a> (Anchor) digunakan untuk menghubungkan satu halaman web ke halaman lain atau ke situs eksternal menggunakan atribut href.

HTML Link Code 
<!-- Tautan Eksternal ke Tab Baru -->
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">Kunjungi MDN Web Docs</a>

<!-- Tautan Internal Halaman Lain -->
<a href="html-media-tabel.html">Materi Media & Tabel &rarr;</a>

<!-- Tautan Email -->
<a href="mailto:support@educode.id">Kirim Email Support</a>

Tag List (<ul>, <ol>, <dl>)

Daftar pada HTML dikelompokkan menjadi 3 jenis: Unordered List (ul) untuk daftar poin bullet, Ordered List (ol) untuk daftar berurutan, dan Description List (dl) untuk istilah beserta definisinya.

HTML Lists Code 
<!-- Unordered List -->
<ul>
  <li>HTML5 - Structure</li>
  <li>CSS3 - Styling</li>
  <li>JavaScript - Logic</li>
</ul>

<!-- Ordered List -->
<ol type="1">
  <li>Buka Editor Kode</li>
  <li>Tulis Kode HTML</li>
  <li>Buka di Browser</li>
</ol>

<!-- Description List -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

Elemen Semantik Layout HTML5

Elemen semantik memberikan makna struktural bagi peramban dan mesin pencari (SEO) dibanding tag netral seperti <div>:

<header>

Berisi logo, navigasi utama, atau judul dokumen.

<nav>

Wadah khusus daftar tautan navigasi utama.

<main>

Wadah konten utama yang unik per halaman.

<article> & <section>

Mengelompokkan ide artikel berserta bab/bagiannya.

<aside>

Berisi sidebar, iklan, atau informasi pelengkap.

<footer>

Berisi hak cipta, kontak, atau tautan tambahan bawah.
