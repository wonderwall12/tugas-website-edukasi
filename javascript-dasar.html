JavaScript Fundamentals & DOM Manipulation

JavaScript adalah bahasa pemrograman client-side yang memberikan kemampuan interaktif pada dokumen web. Halaman ini membahas variabel, fungsi, seleksi DOM, event listener, dan aplikasi interaktif sederhana.

Variabel & Tipe Data JavaScript

JavaScript mendukung deklarasi variabel modern menggunakan const (nilai tetap/konstan) dan let (nilai yang dapat diubah), menggantikan var lama.

JavaScript Code 
// Deklarasi Variabel Modern
const nama = "Budi";       // String
let umur = 20;             // Number
const isStudent = true;    // Boolean
const hobi = ["Coding", "Membaca"]; // Array
const profil = { kota: "Jakarta" }; // Object

console.log(nama, umur, isStudent);
Live Output Log
// Output Console Browser:
nama: "Budi"
umur: 20
isStudent: true
hobi: ["Coding", "Membaca"]

Fungsi (Functions)

Fungsi mengelompokkan sekumpulan perintah agar dapat dipanggil berulang kali. Dukungan Arrow Function () => {} mempermudah penulisan fungsi ringkas di ES6.

JS Function Code 
// 1. Function Declaration
function sapa(namaUser) {
  return "Halo, " + namaUser + "!";
}

// 2. Arrow Function (ES6)
const hitungLuas = (p, l) => p * l;

console.log(sapa("Erika"));
console.log("Luas:", hitungLuas(5, 4));
Live Preview Result
Hasil Eksekusi Fungsi:

sapa("Erika") → "Halo, Erika!"

hitungLuas(5, 4) → 20

Manipulasi DOM (Document Object Model)

DOM menganggap elemen HTML sebagai objek yang dapat diakses dan diubah secara dinamis melalui JavaScript menggunakan document.getElementById() atau document.querySelector().

DOM Code 
// Memilih Elemen
const Judul = document.querySelector("#judul-demo");

// Mengubah Teks & Style
Judul.innerText = "Teks Diubah via JS!";
Judul.style.color = "#6366f1";
Judul.classList.add("highlight");

Event Listener Handling

Event Listener merespons aksi pengguna seperti klik mouse (click), pengetikan keyboard (keyup), atau pengisian formulir (input).

Event Code 
const tombol = document.getElementById("myBtn");

tombol.addEventListener("click", (event) => {
  alert("Event Klik Terdeteksi!");
});
