Modul 2 • Media, Tabel & Form

Tag Media (Image, Audio, Video), Tabel & Formulir

Materi ini membahas cara menyajikan konten multimedia (gambar, audio, video), menampilkan data terstruktur dengan tabel HTML, dan membuat formulir interaktif pengumpulan data pengguna.

Menu Topik
  • Gambar (<img>)
  • Audio (<audio>)
  • Video (<video>)
  • Tabel (<table>)
  • Formulir (<form>)

Tag Gambar (<img>, <figure>, <figcaption>)

Tag <img> menyematkan gambar pada halaman web. Digabungkan dengan <figure> dan <figcaption> untuk memberikan keterangan gambar semantik.

HTML Image Code 
<figure style="text-align: center;">
  <img src="https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=600&q=80" 
       alt="Laptop menampilkan kode program HTML CSS" 
       title="Pengembangan Web Modern"
       style="width: 100%; max-width: 400px; border-radius: 8px;">
  <figcaption style="font-size: 0.85rem; color: #64748b; margin-top: 0.5rem;">
    Gambar 1.1: Ilustrasi Lingkungan Coding Modern
  </figcaption>
</figure>

Tag Pemutar Audio (<audio>)

Tag <audio> digunakan untuk memutar berkas suara atau musik secara native di peramban dengan atribut controls.

HTML Audio Code 
<audio controls style="width: 100%;">
  <source src="https://actions.google.com/sounds/v1/ambiences/outdoor_ambient.ogg" type="audio/ogg">
  Peramban Anda tidak mendukung pemutar audio HTML5.
</audio>

Tag Pemutar Video (<video>)

Tag <video> menyematkan pemutar video langsung di web tanpa plugin tambahan.

HTML Video Code 
<video controls poster="https://images.unsplash.com/photo-1517694712202-14dd9538aa97?w=600&q=80" style="width: 100%; border-radius: 8px;">
  <source src="https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ForBiggerBlazes.mp4" type="video/mp4">
  Peramban Anda tidak mendukung video HTML5.
</video>

Tag Tabel Data (<table>)

Tabel menyajikan data dalam bentuk baris (<tr>) dan kolom (<td>, <th>). Gunakan <thead>, <tbody>, <tfoot>, serta atribut colspan / rowspan untuk tabel kompleks.

HTML Table Code 
<table class="custom-table">
  <caption>Jadwal Kurikulum EduCode 2026</caption>
  <thead>
    <tr>
      <th>No</th>
      <th>Materi</th>
      <th>Durasi</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>HTML5 Fundamentals</td>
      <td>2 Jam</td>
      <td style="color:#10b981;">Selesai</td>
    </tr>
    <tr>
      <td>2</td>
      <td>CSS3 & Flexbox</td>
      <td>3 Jam</td>
      <td style="color:#6366f1;">Sedang Belajar</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2"><strong>Total Durasi</strong></td>
      <td colspan="2"><strong>5 Jam</strong></td>
    </tr>
  </tfoot>
</table>

Formulir & Input Lengkap (<form>)

Formulir HTML memungkinkan pengguna memasukkan data melalui berbagai kontrol input seperti text, email, password, number, date, color, file, range, radio, checkbox, select, dan textarea.

HTML Form Code 
<form action="#" method="POST" class="custom-form">
  <fieldset class="form-fieldset">
    <legend class="form-legend">Identitas Diri</legend>

    <div class="form-group">
      <label class="form-label" for="nama">Nama Lengkap:</label>
      <input type="text" id="nama" class="form-control" placeholder="Contoh: Budi Santoso" required>
    </div>

    <div class="form-group">
      <label class="form-label" for="email">Alamat Email:</label>
      <input type="email" id="email" class="form-control" placeholder="nama@domain.com" required>
    </div>

    <div class="form-group">
      <label class="form-label" for="role">Tingkat Kemampuan:</label>
      <select id="role" class="form-control">
        <option value="pemula">Pemula (Baru Mulai)</option>
        <option value="menengah">Menengah (Paham HTML/CSS)</option>
        <option value="mahir">Mahir (Paham JS & Framework)</option>
      </select>
    </div>
  </fieldset>

  <button type="submit" class="btn btn-primary">Kirim Formulir</button>
</form>
