CSS Dasar, Box Model, Flexbox & Grid

CSS (Cascading Style Sheets) mengatur tampilan visual elemen web. Materi ini mencakup cara menghubungkan CSS, selektor, konsep Box Model, tata letak modern (Flexbox & Grid), animasi, dan variabel CSS.

3 Cara Menghubungkan CSS

Terdapat tiga metode untuk menyisipkan aturan CSS ke dalam dokumen HTML:

1. Inline CSS

Atribut style="" langsung pada elemen HTML.

<h1 style="color: blue;">Teks</h1>

2. Internal CSS

Tag <style> di dalam bagian <head> HTML.

<style>
  h1 { color: blue; }
</style>

3. External CSS (Rekomendasi)

Tag <link rel="stylesheet"> ke berkas .css terpisah.

<link rel="stylesheet" href="style.css">

Selektor CSS & Pseudo-Class

Selektor menentukan elemen HTML mana yang akan diberi gaya visual.

CSS Selectors Code 
/* 1. Selektor Tag Element */
p { color: #334155; }

/* 2. Selektor Class (.) */
.kartu-spesial {
  background: #e0e7ff;
  border-radius: 8px;
  padding: 15px;
}

/* 3. Selektor ID (#) */
#tombol-utama {
  background: #6366f1;
  color: white;
}

/* 4. Pseudo-class (:hover) */
.kartu-spesial:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 16px rgba(0,0,0,0.1);
}

Konsep CSS Box Model

Setiap elemen HTML dianggap sebagai kotak pembungkus yang terdiri dari 4 lapisan: Content (isi), Padding (jarak dalam), Border (garis tepi), dan Margin (jarak luar).

MARGIN (Jarak Luar Elemen)
BORDER (Garis Tepi)

Flexbox Layout System

Flexbox (Flexible Box Layout) mempermudah perataan posisi elemen secara 1 dimensi (horizontal atau vertikal).

CSS Flexbox Code 
.flex-container {
  display: flex;
  flex-direction: row; /* atau column */
  justify-content: space-between; /* align horizontal */
  align-items: center; /* align vertikal */
  gap: 12px;
}

CSS Grid Layout System

CSS Grid mengatur tata letak 2 dimensi (kolom dan baris) secara presisi dan responsif.

CSS Grid Code 
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

Transitions & Keyframe Animations

Buat interaksi halaman web menjadi hidup dan menarik menggunakan transisi halus dan animasi @keyframes.

CSS Animation Code 
@keyframes denyut {
  0% { transform: scale(1); }
  50% { transform: scale(1.08); }
  100% { transform: scale(1); }
}

.animasi-box {
  animation: denyut 2s infinite ease-in-out;
}
